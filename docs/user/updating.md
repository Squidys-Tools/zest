# Updating Zest

Zest checks GitHub Releases on the schedule in **Settings → Update
frequency** (daily, weekly, or never). Each launch asks whether the cadence
says it is time to check; when a newer release exists Zest shows a toast and
adds an **Update to Zest …** item to the tray menu, which opens the release
page in your browser. The tray item also appears on the next launch after a
check found something — the prompt survives restarts but never interrupts
a task.

Downloading and installing the MSI is manual for now: Zest never downloads
binaries and never restarts itself.
