# Settings

Right-click the tray icon → **Settings**. It is a plain form window. Open it
once, set it, forget it.

## General

| Setting | Options | Default |
| --- | --- | --- |
| Hotkey | Press-record ("press your shortcut") | `Shift+F` |
| Output location | Beside original / a chosen folder / ask each time | Beside original |
| File naming | Auto-suffix with new extension, numbered on collision (`photo (1).jpg`) | On |
| Theme | System / light / dark | System |
| Font | Dropdown for the universal app font | Segoe UI Variable |
| Launch at startup | Opt-in, writes HKCU Run key | Off |
| Update frequency | Daily / weekly / never | Weekly |
| Warn before lossy-to-lossy conversion | Toggle | On |

## Quality defaults

| Setting | Options | Default |
| --- | --- | --- |
| JPEG quality | Slider 1–100 | 90 |
| Video quality | Low / medium / high / lossless preset | Medium |
| Audio bitrate | Dropdown | 192 kbps |

## Colors

The active radial sector uses a smoothed gradient of 1–3 colors. Add or remove
pickers as you like (minimum 1, maximum 3).

Settings persist to `%LOCALAPPDATA%\Zest\settings.json`.
